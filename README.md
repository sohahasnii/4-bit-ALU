# 4-Bit ALU Using Verilog HDL

A 4-bit Arithmetic Logic Unit (ALU) designed using Verilog HDL and verified through behavioral simulation in AMD Xilinx Vivado.

The ALU performs eight arithmetic and logical operations on two 4-bit inputs, with operation selection controlled by a 3-bit control signal.

## Features

- 8 arithmetic and logical operations
- 4-bit input operands and output result
- 3-bit operation selection
- Carry-out flag for addition
- Carry/no-borrow indication for subtraction
- Zero flag for detecting a zero result
- Verilog RTL design and testbench
- Behavioral simulation using XSim

## Operations

| `sel[2:0]` | Operation | Function |
|:---:|---|---|
| `000` | ADD | `A + B` |
| `001` | SUB | `A - B` |
| `010` | AND | `A & B` |
| `011` | OR | `A \| B` |
| `100` | XOR | `A ^ B` |
| `101` | NOT A | `~A` |
| `110` | Shift Left | `A << 1` |
| `111` | Shift Right | `A >> 1` |

## Design Specifications

| Parameter | Specification |
|---|---|
| Input width | 4 bits each |
| Output width | 4 bits |
| Operation select | 3 bits |
| Number of operations | 8 |
| Design type | Combinational logic |
| HDL | Verilog |
| Simulator | Vivado XSim |

The main result contains the lower four bits of the selected operation. For addition, the fifth bit is exposed through `carry`. For subtraction, `carry = 1` indicates no unsigned borrow. The `zero` output is high whenever the result is `0000`.



## Getting Started

### Requirements

- AMD Xilinx Vivado
- Verilog HDL support


No physical FPGA board is required to run the simulation.

## Implementation Details

- `always @(*)` describes combinational behavior.
- A `case` statement selects the requested operation.
- A 5-bit intermediate signal preserves the additional arithmetic bit.
- The zero flag is generated by comparing the result with `4'b0000`.
- Default assignments prevent unintended latch inference.
